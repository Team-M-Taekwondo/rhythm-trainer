Count sections

These times are positions in the audio file, not stopwatch times during the run. Every division on a speed match plays the same file, so they share one set — then each division's speed decides when the counting is actually heard (20.4s into the file lands at 17.7s for Cadet at 1.15×, 20.0s for Youth at 1.02×). Editing here changes it for every division on this recording.

Mark the stretches where the audio counts out loud in Korean (Taegeuk Pal Jang's two 8-count sections, for example). Those play at the recording's own speed, so the count itself never changes length however fast the match is.

Play the recording, then tap Mark start when the counting begins and Mark end when it stops. Fine-tune the numbers after. Playback here is always 1× — you're marking the file, not a division.

Where the Poomsae Intro drill stops. The time is a position in the recording, so one point covers every division on this file — they all stop at the same movement, their speed match just shifts when it's heard. Use Play recording in Count sections above, then set it from the playhead (or type it).

Settings

Uses the device's built-in Korean speech. Biggest quality boost: install the enhanced Korean voice — on iPhone/iPad/Mac, Settings → Accessibility → Spoken Content → Voices → Korean → download Yuna, then pick it above.
